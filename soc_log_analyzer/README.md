# SOC Log Analyzer

A Python project that simulates a SOC (Security Operations Center) analyst reviewing security logs.

## Features

- Reads a security log file.
- Counts different security events:
  - LOGIN_FAILED
  - LOGIN_SUCCESS
  - ACCOUNT_LOCKED
  - PASSWORD_CHANGED
- Detects suspicious IP addresses.
- Assigns risk levels:
  - High Risk
  - Medium Risk
  - Low Risk
- Identifies the top attacker.
- Generates a SOC report automatically.
- Provides security recommendations.

## Files

### soc_log_analyzer.py

Main Python script.

### security_log.txt
